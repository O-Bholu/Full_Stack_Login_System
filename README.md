# Full_Stack_Login_System
    This is a full-stack Login System built using React for the frontend, Tailwind CSS for styling, and MySQL as the database. The application allows users to register and log in securely, with data stored in a database. It demonstrates complete authentication flow from frontend UI to backend and database integration.
